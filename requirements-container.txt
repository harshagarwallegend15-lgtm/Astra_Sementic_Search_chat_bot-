# Container dependencies for the FastAPI console.
#
# Derived from requirements.txt minus everything the deployed image never
# loads. The full requirements.txt installs Streamlit, langchain-ollama, pytest
# and httpx, which together add hundreds of MB of build time and image weight
# for code paths (`app.py`, the local Ollama provider, the test suite) that a
# container serving api.py never executes. The .dockerignore already excludes
# app.py, so importing it is impossible anyway.
#
# If you ever want to run the Streamlit UI in a container, use the full
# requirements.txt and a different CMD.
